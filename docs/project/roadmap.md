# Roadmap — dates are provisional planning targets

| Window | Deliverable | Exit evidence |
|---|---|---|
| 30–31 Oct | Architecture review | Approved design/ADR, scope and owners |
| 01–04 Nov | Data, ground truth, baseline | Reproducible baseline and provenance |
| 05–10 Nov | ML pipeline | Matching metrics and hard negatives |
| 11–15 Nov | Agent + human review + mock tracker | End-to-end mock flow and policy tests |

| 26 Nov | Expected final | Confirm details with organizers |

**Critical path:** dataset permission → labels → baseline/matching → report approval flow → experimental evidence → financial story. UI polish is not on the critical path.

Suggested roles (4 people): Architect/backend/privacy, ML/evaluation, agent/integrations, product/business/ROI. For 2–3 people reduce UI before sacrificing evidence quality.

No task is complete without test output; negative measured results are reported, not hidden.
